A plugin IDE, inside the settings app. Write a Lua plugin, run it as you type,
and install it without leaving the phone. Alongside that: notifications for
work that finished while you were elsewhere, and a real code editor behind
"Edit as JSON".

### The plugin editor

The whole thing, on a phone:

- **Write, run and install a plugin** from the settings app, out of a workspace
  for drafts that is kept apart from what is installed.
- **A Lua lexer and parser that never stop at a broken file**, so the editor
  keeps working while you are mid-edit.
- **It knows what every name in your plugin means** — every name a plugin can
  reach, proven against the sandbox — so it can tell you what is wrong without
  ever crying wolf, put squiggles under it, and explain the API name at the
  caret.
- **Suggestions at the caret**, a problems list and an outline beside the code,
  go-to-definition and find-all-references, find, replace, go to line, and
  rename.
- **Block folding**, jump to a block's ends, and a gutter you can jump from.
- **Start from a template, a file or another draft**, with a preview of what
  each template looks like first.
- **Look back through a plugin's versions and restore one.**
- **A row of code keys above the keyboard**, arrangeable, that suggests there
  when the editor is short.
- **Run a plugin as it is typed and poke at it while it runs**, with a preview
  session that keeps its console, and a look at what the installed plugin
  stores beside the preview's.
- Motion that respects Reduce motion, your text size, and a speed floor.

### Notifications

**Say what finished while the user was somewhere else** — downloads included,
and the ones that used to finish silently now report themselves. "What's new"
says when it is fetching.

### Layouts

- **"Edit as JSON" becomes a real code editor**: a monospaced face, a fast
  field, and a formatter that stops counting.
- **Copy and paste one layer**
  ([#105](https://github.com/wasi-master/wmkeyboard/issues/105)).
- **Move a key between rows, and drag one anywhere in the grid.**
- **The letters a key stands for are a control**, not a JSON field.
- T9 and Compact QWERTY were shipped but unreachable; they are reachable now.
- Hide the 🌐 key on every layout
  ([#139](https://github.com/wasi-master/wmkeyboard/issues/139)).

### Keyboard

- **Swipe off ?123 or ABC to type one key from that layer**
  ([#108](https://github.com/wasi-master/wmkeyboard/issues/108)).
- The strip and the nav bar take a colour of their own
  ([#109](https://github.com/wasi-master/wmkeyboard/issues/109)), and every bar
  row takes the strip fill.

### Suggestions and typing

- **The held word's menu opens an editor**, not a rank dial
  ([#138](https://github.com/wasi-master/wmkeyboard/issues/138)).
- **Never suggest takes the word off the strip immediately**
  ([#127](https://github.com/wasi-master/wmkeyboard/issues/127)).
- An empty field is a sentence start, and has openers to offer.
- A mark hugs the word whichever branch it leaves by
  ([#123](https://github.com/wasi-master/wmkeyboard/issues/123)).
- A second sum on the same line gets its own chip
  ([#137](https://github.com/wasi-master/wmkeyboard/issues/137)).
- The English list gets its contractions back
  ([#128](https://github.com/wasi-master/wmkeyboard/issues/128)).

### Modes

**A mode decides whether the keyboard spaces for you**
([#124](https://github.com/wasi-master/wmkeyboard/issues/124)).

### Glide

A run of fixes for words lost around a restarting field
([#113](https://github.com/wasi-master/wmkeyboard/issues/113)) and for the lift
decoding a different word than the preview promised
([#121](https://github.com/wasi-master/wmkeyboard/issues/121)). The octopus
keys and the emoji chips follow a glided word instead of freezing on it.

### F-Droid

**Every online service and download can use another server**, with free
currency-rate sources and a weather chip that waits for a tap.

### Under the hood

The first Robolectric tests that drive the keyboard service itself, a shared
harness behind six of them, and twelve setting families lifted off the
`KeyboardSettings` class ceiling.
