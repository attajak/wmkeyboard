Snippets grow folders and Espanso support, the colour picker is rebuilt around
a hue wheel, and the text-editing panel becomes a layout you can edit like any
other.

### Snippets

- **Folders**, each with its own switch, so a whole set can be turned off at
  once.
- **Espanso files read and written**, so an existing Espanso config comes
  across.

### Layouts and panels

- **The text-editing panel is a layout you can edit**, same editor as the
  letters.
- **A key can span rows.**
- **A layout's own font**, and a label size per key.
- The corner hint can be hidden on a single key.

### Themes

- **The colour picker is rebuilt around a hue wheel** instead of sliders.

### Gestures

- **A glide can draw the apostrophe**, and a flick from the apostrophe key
  appends `'s`.

### Voice

- **Interactive voice typing modes**, so dictation can be driven rather than
  just started.

### The toolbar

- **A row of its own**, with a hold action per tool, and cursor tools that
  repeat in the toolbox too.
- **A Selection mode tool.**

### Settings

- Snippet settings move to a Text Expander screen, clipboard settings to their
  own Features screen.

### Fixed

- The strip pickers no longer steal focus from the field.
- The layout editor stops writing an older copy of a key back over your edit.
- The hex field stops prepending `FF` to a six-digit colour.
- Accessibility: the touch-exploration capability the pass-through needs is
  declared, and the pass-through region survives a filter rebuild.
