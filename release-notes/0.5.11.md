The keyboard pairs with your computer over KDE Connect, chats with your AI model
without leaving the text box, reads Signal sticker packs and shows you every
request it makes. On Play, the heavy offline features now download the first
time you use them.

### KDE Connect

- **Pair the keyboard with a computer running KDE Connect, GSConnect or
  Valent.** The keyboard is its own device on the network, so the KDE Connect
  app is not needed. From the new tool: a touchpad, typing on the computer with
  glide and corrections, Esc, Tab, arrows, F-keys and sticky modifiers, the
  computer's media players and volume, sending the clipboard, the field's text
  and files, run commands with live output, a slideshow remote, ping, ring and
  lock ([#285](https://github.com/wasi-master/wmkeyboard/issues/285)).

### AI

- **Chat with the model on the keyboard's AI panel.** A Chat mode sits beside
  the actions, and it is the same conversation the settings app has, so a chat
  begun on the keyboard carries on in the app and back. Insert, Copy and Write
  again on the newest answer
  ([#280](https://github.com/wasi-master/wmkeyboard/issues/280)).

### Voice

- **Dictate to your own transcription server.** Anything that speaks OpenAI's
  `/v1/audio/transcriptions` works: whisper.cpp's server, speaches, LocalAI,
  Groq, OpenAI. The docs carry a recipe for each
  ([#286](https://github.com/wasi-master/wmkeyboard/issues/286)).
- **Whisper no longer types words nobody said.** A silent clip used to come back
  as "Thank you."; it is now held back, and a blank clip in continuous mode
  counts toward the silent-retry limit instead of listening forever.
- **Spoken punctuation goes past the end of a sentence**: quotes, brackets,
  dashes, slash, at sign, hashtag, currency and percent signs and the operators,
  each spaced the way a typed one would be.
- **The voice tool stops a running dictation**, and the stop press lands
  anywhere on it ([#283](https://github.com/wasi-master/wmkeyboard/issues/283)).

### Stickers

- **Add Signal sticker packs from a pack link**, or share one to the app.
  Animated PNG stickers become animated WebP, and go as a GIF where an app
  refuses WebP ([#291](https://github.com/wasi-master/wmkeyboard/issues/291)).
- **Background removal works without Play services** in the full build, on a
  model of the app's own ([#278](https://github.com/wasi-master/wmkeyboard/issues/278)).
- The add button in My stickers opens the photo picker
  ([#281](https://github.com/wasi-master/wmkeyboard/issues/281)).

### Translate

- **Translate on device** with ML Kit: no connection, nothing sent. Pick Online,
  On device or Automatic, choose the source language or swap the pair. Full
  builds carry it; on Play it downloads when first used.

### Privacy

- **Settings › Privacy › Network activity** lists every request the keyboard
  makes: a live line while it happens, a chart for today, 7 and 30 days, which
  feature asked, which server answered, and a sheet per request saying why it
  happened and what it carried.
- **Password and code handling on the clipboard is opt-in.** Sensitive clips
  are kept like any other until you turn the masking and the forget-after-paste
  timer on.

### Clipboard

- **A list view beside the grid**, optional clip numbers that survive a search,
  and **editing a clip on the keyboard**: hold a text clip and pick Edit.

### Dictionaries

- **Android's own word lists are the default for 23 languages**, beside the
  counted lists, with US and UK English and European and Brazilian Portuguese.
- **AOSP dictionaries import in full**: word pairs, shortcuts, and the version 4
  dictionaries HeliBoard and LeanType write, user history included.
- **An imported word list no longer switches glide off for its language**
  ([#288](https://github.com/wasi-master/wmkeyboard/issues/288)).

### Typing

- **Japanese kana typed without marks still finds the word**: かつこう finds
  学校 on the flick pad and the JIS kana layout
  ([#293](https://github.com/wasi-master/wmkeyboard/issues/293)).
- A glide into a keyboard text box adds a word instead of replacing the last one
  ([#300](https://github.com/wasi-master/wmkeyboard/issues/300)), and a word
  finished early teaches only the letters you drew
  ([#262](https://github.com/wasi-master/wmkeyboard/issues/262)).
- Swiping to add 's works on English words typed on Banglish.
- The long-press popup keeps each emoji inside its own column
  ([#298](https://github.com/wasi-master/wmkeyboard/issues/298)).
- Tapping a saved-login chip vibrates like a key
  ([#250](https://github.com/wasi-master/wmkeyboard/issues/250)).

### Tools

- **The suggestion strip can be hidden under an always-open tools row**
  ([#302](https://github.com/wasi-master/wmkeyboard/issues/302)).
- A currency chip writes its result as a name, a symbol or a code
  ([#299](https://github.com/wasi-master/wmkeyboard/issues/299)).
- The calculator has a phone layout with 1 2 3 on top
  ([#294](https://github.com/wasi-master/wmkeyboard/issues/294)).

### Smaller on Play

Offline Whisper, the sticker editor's background remover and handwriting
recognition are on-demand modules on Play now, like the AI runtime and the
translator. An install that never uses them is about 11 MB smaller per
architecture.
