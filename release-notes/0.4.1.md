A small follow-up to 0.4.0.

### Added

- **A tappable path strip** on deep settings screens, so you can see where you
  are and step back out.
- **Fine-grained key width and row height** in the layout editor.
- **Shift turns the cursor tools into shift+arrow**, so the toolbar can select
  as well as move.
- **Hold a cursor tool to repeat its move.**

### Fixed

- LuaJ's helper classes keep their own package, which R8 was collapsing.
- Fastlane resolves a handed-over AAB against the repo root.
- Theme deck captions on the docs site get their top margin back.
