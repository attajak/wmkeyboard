The prediction engine is rebuilt around a fuzzy beam walk, the AI tool grows
providers and a history, photo backgrounds arrive, and stickers get an editor.

### Prediction, rebuilt

The engine stopped scanning and started walking:

- **A trie-guided fuzzy beam search** over all three tries, through one shared
  node-level walker, with one walk per keystroke and correct invalidation.
- **Touch coordinates score continuously** inside the walk. The keyboard
  captures where you actually tapped and feeds its own touch model.
- **Context**: learned bigrams re-rank mid-word completions, trigrams pick the
  next word, a sentence start has its own context, and a gesture prior and a
  per-app recency overlay sit on top.
- **Learning that persists**: a bounded personal lexicon with lazy decay, and
  per-pair revert learning with adaptive confidence.
- **Downloadable corpus n-gram packs** (English and romanized Bengali) behind a
  context reranker, open to every channel and measured.
- Missing-space and number-row slip corrections, and a word-join chip, so
  `some` + `thing` offers `something`.
- An offline eval harness with committed quality baselines, plus benchmarks for
  the hot path and for the memory-mapped trie.

### Bengali

**Type Banglish, get Bengali script.** And Avro was made to behave like Avro,
with siblings ranked by what was actually typed.

### The AI tool

Grok, DeepSeek and any OpenAI-compatible service; actions you can add, edit,
reorder and switch off; an ask-each-run action that can start from a saved
prompt; a view of what the model *changed* rather than only what it wrote,
built on a new text-comparison engine; an optional history with a rule for what
may be recorded; a running model download shown on the panel; and long answers
that no longer get cut off in silence.

### Themes

- **Photo backgrounds**: browse Unsplash and Pexels, download into a rotation
  pool, and let the background rotate.
- Photos decode at the size they are drawn, through one image loader shared
  across the process.
- Per-theme font and sound, addon dependencies, animated GIF and WebP
  backgrounds, per-key-class image textures, single-key style overrides,
  sticker decals over the grid, key-press particle bursts with custom images,
  tool shape and outline, and popup overrides.

### Stickers

An editor with browsable GIF categories, that keeps the picture an edit started
from, resumes an edit, and shows the brush before it paints.

### Emoji

Shortcode suggestions that outlive the space, an animated version sent from a
long press, and the emoji itself sent as a sticker, drawn in the real font and
encoded by the sticker tool.

### Tools and chips

- **An app launcher**: open any app or screen from the keyboard.
- **One-time codes from notifications**, offered as a strip chip.
- Smart chips for scaled amounts, `nPr`/`nCr`, bare division, and the scale
  words "hajar" and "koti"; chips size themselves instead of overflowing.
- Fancy Text becomes one keyboard with a style strip, added and removed by its
  own tool.
- Icon packs switchable from the themes tool, tool background width, and theme
  layout overrides.

### Keys and input

Split key repeat, shaped popups, a separate height per popup bubble style,
haptics defaulting to the keyboard tap, number pads worth reaching for,
seven key shapes behind a picker with previews, and `?123` left behind after a
punctuation character.

### Hardware keyboards

Hotkey badges, a Ctrl+digit chord, and a macOS mode.

### Settings

The app takes Manrope and Inter on a type scale of its own, icons on every row
with gradient tool colours, an About → Storage screen matching the system's own
figures, search that finds the words people actually type, and a Tools screen
that stops composing sixty rows to draw ten.

### Under the hood

User-facing strings moved to resources, the keyboard's world stopped being
rebuilt on every keystroke, every `.wmdict` halved, corpus n-grams stored as
ids rather than re-spelled words, and full native debug symbols generated for
release builds.
