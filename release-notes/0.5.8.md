Thirty more selection actions with a Find and replace panel and an Undo that
walks back, a Banglish-to-Bangla converter for whole texts, an icon for any
key, and a theme editor that previews on the keyboard itself.

### Selection

**The selection bar grows to about fifty actions** — case changes, sorting,
encoding, wrapping, counting, and more — each of which can be switched on or
off, with:

- **An Undo that walks back** through what the actions did.
- **A Find and replace panel** behind the Replace chip.
- **A screen of its own** in settings, and a toolbar key that turns the
  selection actions on and off
  ([#177](https://github.com/wasi-master/wmkeyboard/issues/177)).
- Select all leading every row.

### Bengali

**A converter between Banglish and Bangla for whole texts**, not just as you
type.

### Keys and gestures

- **Pick an icon for any key, the space bar included**
  ([#187](https://github.com/wasi-master/wmkeyboard/issues/187)).
- **A quick swipe down on a key types its corner hint**
  ([#178](https://github.com/wasi-master/wmkeyboard/issues/178)).
- **A swipe from a punctuation key to `s` adds `'s` to the last word**
  ([#169](https://github.com/wasi-master/wmkeyboard/issues/169)).
- **A panel takes shift, Fn, layout and chorded keys**
  ([#183](https://github.com/wasi-master/wmkeyboard/issues/183)).

### Prediction

- **A word typed without its accents is corrected**, and Enter corrects the way
  space does ([#200](https://github.com/wasi-master/wmkeyboard/issues/200)).
- **The word two back vouches for a candidate**, through a stored skip-gram
  ([#195](https://github.com/wasi-master/wmkeyboard/issues/195)).
- **A word typed on digit-hinted keys also offers the number**
  ([#181](https://github.com/wasi-master/wmkeyboard/issues/181)).
- Long words are cut in the middle, with an option for the end.
- A stray space before punctuation is removed, and patterns can see the mark.

### Glide

- **The walk out to Shift is cut from a stroke**, and a pass over Shift can
  capitalize one letter
  ([#163](https://github.com/wasi-master/wmkeyboard/issues/163)).
- **A swiped text-expansion trigger expands**
  ([#170](https://github.com/wasi-master/wmkeyboard/issues/170)).
- A word drawn in full is not overtaken by the word it starts, and an early
  lift's strip offers the word's kin
  ([#167](https://github.com/wasi-master/wmkeyboard/issues/167),
  [#168](https://github.com/wasi-master/wmkeyboard/issues/168)).
- A swipe's readings are found where its word stands, and 500 are kept
  ([#199](https://github.com/wasi-master/wmkeyboard/issues/199)).

### Themes

- **The theme editor previews on the keyboard itself**
  ([#148](https://github.com/wasi-master/wmkeyboard/issues/148)).
- **A None key shape leaves only the labels on the board**
  ([#149](https://github.com/wasi-master/wmkeyboard/issues/149)).

### Modes

- **Bind a mode to a field's shape or its hint text**
  ([#186](https://github.com/wasi-master/wmkeyboard/issues/186)).
- **A mode can be switched off without deleting it**
  ([#152](https://github.com/wasi-master/wmkeyboard/issues/152)).
- Incognito keeps the login and code chips, and the saver modes drop less by
  default ([#151](https://github.com/wasi-master/wmkeyboard/issues/151)).

### Voice

**Press and hold the mic tool to pick a voice typing mode**
([#173](https://github.com/wasi-master/wmkeyboard/issues/173)), and the
keyboard says when Quick Settings is blocking the microphone
([#193](https://github.com/wasi-master/wmkeyboard/issues/193)).

### Dictionary

Sort the personal dictionary by weight, name or date added
([#194](https://github.com/wasi-master/wmkeyboard/issues/194)), delete edits
imported lists, and learning judges edits rather than the caret
([#190](https://github.com/wasi-master/wmkeyboard/issues/190),
[#159](https://github.com/wasi-master/wmkeyboard/issues/159),
[#164](https://github.com/wasi-master/wmkeyboard/issues/164)).

### The launcher tool

Apps per row, icon size and shape, and hidden apps
([#198](https://github.com/wasi-master/wmkeyboard/issues/198)).

### Elsewhere

- **The app can show as "WMK" in the launcher**, behind a switch
  ([#140](https://github.com/wasi-master/wmkeyboard/issues/140)).
- **The language picker can be a sideways carousel**
  ([#150](https://github.com/wasi-master/wmkeyboard/issues/150)).
- **VS Code's keys in both code editors**, plus undo, redo, copy, paste and the
  caret's place in the plugin editor.
- **R8 mappings and native symbols are attached to the GitHub release**, so a
  crash report from a downloaded APK can be retraced.
- The ML Kit registrar constructor R8 was stripping is kept
  ([#146](https://github.com/wasi-master/wmkeyboard/issues/146)).
- A swipe up the page scrolls past sliders instead of through them
  ([#153](https://github.com/wasi-master/wmkeyboard/issues/153)).
