The first tagged build. Two months of work, and everything the keyboard is
built on: the typing engine, the layout and theme systems, the toolbox, and the
first ~150 languages.

This tag predates the public releases — it was never published to a store — but
it is where all of it starts.

### The typing core

- **A prediction engine** over a trie, with autocorrect, a phonetic index and
  confidence gating; contact names and seed bigrams feed it.
- **SHARK²-style gesture typing**, with a mid-swipe candidate preview, a
  themeable trail, swipe-undo, space-glide for several words in one stroke, and
  a cooldown so a stray drag does not start a swipe.
- **Avro-style Bengali phonetic transliteration** — type Banglish, get Bengali —
  with conjunct-aware backspace, contextual vowel keys, the য়-glide, and the
  Avro autodict loanwords imported.
- Snippets with template variables, auto-expanding on a typed trigger.
- A never-suggest blacklist, contact-email autocomplete, and importable custom
  dictionaries per language.

### Languages and scripts

Grown from Bengali and English to **roughly 150 languages across 20-odd
scripts**: Korean with a Hangul composer, Japanese, Chinese Pinyin, Vietnamese
Telex and VNI, Arabic and Hebrew right-to-left, Greek, Hindi, Russian, Persian,
Thaana, Ethiopic, Tibetan, Syriac, Cherokee, Tifinagh, Sami, Yiddish, and the
constructed ones — Lojban and Klingon included. Layouts load from JSON assets,
each language carries its own script and composer, and per-script fonts are
picked from a curated library.

Alternative Latin layouts too: AZERTY, Dvorak, Colemak, Workman, Halmak, IPA,
and a Fancy Text language with 22 Unicode "font" layouts.

### The keyboard itself

Split, floating, one-handed and resizable, with per-row heights, a symbol row,
reorderable bars, icon keys, a layer-aware number row, numeral-system
switching, and an inputType-aware board that turns into the right keypad for
the field. Ctrl, Alt and Meta send real key events; a physical keyboard routes
through the same pipeline.

### Themes

A full theme engine with an editor and import/export: gradients, key shapes,
image backgrounds with crop and blur, animated themes, per-script fonts,
synthesized key sounds, and a crossfade when you switch.

### Layouts

A serializable layout model and registry, a gallery, and an editor that edits
keys, rows and widths — with an Fn layer, raw JSON editing with syntax
highlighting, and import/export.

### The toolbox

A Gboard-style customizable toolbar over about thirty tools: clipboard history
with pinning, expiry, search, link previews and screenshots; translate; GIF and
sticker search; web and image search; camera; OCR, QR and document scanning;
Wikipedia; a calculator; unit and currency conversion; a password generator; a
calendar; a level and compass; media transport; a typing-speed test; and an AI
tool running on-device LLMs through LiteRT-LM.

### Emoji

A full overhaul to Unicode 17.0: semantic bilingual search, dual skin tones,
favourites you can reorder, prediction, an emoji row with fixed or scrolling
slots, swipeable category tabs, and custom sticker packs with `.wmstickers`
import and export.

### Voice, handwriting and grammar

Dictation in a panel or on the strip, an offline Whisper engine with its own
model downloader, handwriting via ML Kit digital ink — and by swiping on the
keyboard itself — and an offline grammar checker built on Harper, exposed as a
system spell checker.

### Modes and privacy

Per-app keyboard modes bound to the text field, a Chat and a Writing mode with
their own toolbars, auto-incognito in private browsing fields, a toolbar and
clipboard hidden on the lock screen, and password-manager chips in the strip.

### The settings app

Grouped Material pages, search across every setting, full-config export and
import with per-part toggles, and an accessibility pass with a reduce-motion
setting that reaches past the toolbar.
