A release about reach: 862 Keyman keyboards converted and shipped, 40 more
layouts of our own, and a documentation pass that checked every claim the site
makes against the source.

### Keyman keyboards

The Keyman ecosystem covers scripts nothing else does. This release ships a
complete `.kmx` parser, a rule interpreter proved against the keyboards' own
example files, and a touch-layout converter that all 867 upstream boards pass
cleanly. **862 layouts, covering 485 languages**, with the rules downloaded on
demand so a keyboard types what its author actually wrote. A `.kmp` package
opens whole, grid and rules together, and a touch layout you picked can be
imported on its own.

### Layouts and scripts

- **40 new layouts**, and 60 defects fixed in the ones already shipped.
- Fonts ride along for the minority scripts, Vai, Osage and Adlam included.
- A key that opens the system keyboard picker.

### Typing and settings

- Every remaining settings row has an icon.
- Network features hold back on a metered connection.
- A batch of shipped defaults reworked toward what people actually leave on.
- Glide typing no longer switches itself off when you change language, and a
  swipe now decodes against the layout that is actually on screen.

### Privacy

A fingerprint lock you can put on chosen settings screens and delete buttons.

### Emoji

Skin tone during setup, hold to invert the tone, and a longer recents row.

### Themes

An auto slot can hold a whole theme set, so day and night can each have one.

### Elsewhere

A rebuilt documentation homepage with a live theme deck, per-edition privacy
policies with a deletion page, separate Play and F-Droid listings, a security
policy, and a documentation pass that corrected 590 false claims. The docs are
now mirrored to the GitHub Wiki automatically.
