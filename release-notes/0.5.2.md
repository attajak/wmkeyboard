The largest release since the first one: a full settings reorganisation, the
first batch of tracked issues closed, and a keyboard that finally answers for
the word the caret is touching.

### Settings, rebuilt

The settings app was reorganised end to end rather than grown further.
Languages come first, layouts have one door, and Typing became a hub of six
pages. Key press, Appearance, Layout and Emoji split apart; every screen now
reads as a few short lists instead of one long one; one control makes one
decision, and a tool's page links out rather than restaging what it links to.
Along the way: per-page resets, pinned previews, a pull to refresh, and a
choice too wide for a row becomes a value row and a sheet that says what each
option does.

**Search** ranks by kind and history rather than by words alone, and the rows
it could not find before are indexed.

### Snippets

Several expansions per trigger and linked snippets, with a screen to edit them,
triggers that may hold spaces, and import/export that carries it all
([#69](https://github.com/wasi-master/wmkeyboard/issues/69),
[#53](https://github.com/wasi-master/wmkeyboard/issues/53)).

### Keys and gestures

- **Drag off a modifier key to fire the chord**
  ([#67](https://github.com/wasi-master/wmkeyboard/issues/67)).
- **Hold and release picks from the alternates popup.**
- **Backspace swipes by character, with a delete preview**
  ([#36](https://github.com/wasi-master/wmkeyboard/issues/36)).
- The floating key preview can be placed and coloured
  ([#65](https://github.com/wasi-master/wmkeyboard/issues/65)); the more keys

### Tools

- A copied code is offered as a paste chip anywhere
  ([#66](https://github.com/wasi-master/wmkeyboard/issues/66)).
- The media tool pins itself while music is playing.

### Dictionaries

Per-language dictionary switches and a dictionary bar, word lists that ship no
frequencies are kept, and a learned word's spelling and weight can be edited
([#47](https://github.com/wasi-master/wmkeyboard/issues/47)).

### Rows

The fancy-text style strip and the tools row each take a slot in the row order,
with a toggle for each.

### Typing test

Autopilot, with the touch areas made visible and its effect drawn as large as
you like; Bangla is scored by the word and practises the real strip.

### Themes

Colour, size, speed, spread, gravity and duration for key press effects.
