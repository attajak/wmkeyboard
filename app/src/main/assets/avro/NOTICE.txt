The files in this directory are data from ibus-avro
(https://github.com/omicronlab/ibus-avro), Copyright (C) OmicronLab, and are
covered by the Mozilla Public License 1.1 (assets/licenses/mpl-1.1.txt). The
source form of each is that project's file of the same purpose:

  phonetic.json      avrolib.js (the patterns of OmicronLab.Avro.Phonetic)
  regex.json         avroregexlib.js (the patterns of AvroRegex)
  suffix.json        suffixdict.js
  autocorrect.json   autocorrect.js
  search.json        the first-letter table lists in dbsearch.js, and the
                     first letters of each table in avrodict.js

Avro's dictionary itself (avrodict.js) is not here: the keyboard downloads it
from the WM Keyboard data repo (data/bn/bn_avro_dictionary.txt.gz) under the
same licence, re-encoded as one word per line under "@table" headings, with
the source's eleven "Ȁc" typos written as the "‌" (ZWNJ) they were
meant to be.

Only the encoding changed (JSON and plain text instead of JavaScript). The code
that reads them, core/prediction/.../AvroDesktop.kt, is WM Keyboard's own and
MIT licensed.
