# Screenshot shoot list

219 shots left. Generated by `shootlist.py` — re-run it any time to regenerate with the remaining shots only.

## How to use this

1. Pick one batch below and get to the screen named in its heading.
2. Take the shots **in the listed order**, one device screenshot each (Power + Volume-Down).
3. Don't take any other screenshots in between — order is how they get matched up.
4. Run the import command printed at the top of the batch.
5. If you skip a shot, note which number you skipped and pass `--skip N` (repeatable) to the import command.

Shots go to `/sdcard/DCIM/Screenshots` on the device; the importer pulls the newest N, converts them to WebP, drops them in the right asset folder, swaps the placeholder in the page, and marks the manifest entry done.
