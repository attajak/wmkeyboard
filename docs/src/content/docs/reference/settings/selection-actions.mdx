The Selection actions screen is the switch and two choices, then three doors: the Actions list, the AI buttons and the Time zones. This page is the field reference. For what the feature is and how each action behaves, start at [Selection actions](/smart/selection-actions/).

## Options

<SettingsPath path="Advanced / Selection actions" />

| Setting | Control | Default |
|---|---|---|
| Selection actions | Toggle | Off |
| Where it appears | Choice of 2 | **Own row** |
| Read what is selected | Toggle | On |
| Actions | Screen | 28 of 45 on |
| AI buttons | Screen | None |
| Time zones | Screen | UTC and the device's zone |

**Selection actions** is the whole feature. Nothing below it is read while it is off, and no selection raises anything.

**Where it appears** is either *Own row* or *Suggestion strip*. Own row gives the bar a row of its own above the keys, which arrives with the selection and leaves with it, so the keyboard is one row taller while it is there. That row is called **Selection actions** in the row list on [Rows & bars](/reference/settings/rows/#row-order), where you can move it above or below the suggestion strip. Suggestion strip draws the actions over the strip instead and costs no height, since there are no word suggestions to show while text is selected. Under that choice the strip goes back to the toolbar whenever a panel is open, because the arrow on that row is the way out of the panel.

**Read what is selected** decides whether a selection is read as a phone number, an address or a link, or only ever as plain text. With it off you keep every action that works on any text and lose Call, Message, WhatsApp, Email, Open, QR and Contact, because none of those mean anything without the reading. Phone shapes come from the formats you saved under [Phone number formats](/reference/settings/phone-formats/).

## Actions

<SettingsPath path="Advanced / Selection actions / Actions" />

A field at the top searches the actions by name and description. Below it, **Order on the bar** shows the actions that are on in the order the bar draws them; its pencil turns them into a draggable list. Undo is always first and is not in the list. Under that, seven folded groups hold every action with a switch each; an action with settings of its own (AI, Zones) has an arrow to them.

The list is an allow list, not a guarantee: an action that is on is drawn only where it applies, and a few need a tool or an app as well.

Search and Translate are off to start with, because both are a round trip to a network service and neither is what a selection usually means. The chat markers, the programmer's cases, Speak, Zones, Map, Calendar and the decoders are off because each is a taste rather than a need, and the row is long enough already.

## AI buttons

<SettingsPath path="Advanced / Selection actions / AI buttons" />

A checkbox per AI action, in the AI tool's own order. Each picked action gets a chip beside the AI chip that runs it on the selection at once, with the result landing in the AI panel ready to apply. An action that asks for its prompt each run (Custom) is not offered, since it cannot be a one-tap button. **Manage AI actions** opens the [AI actions](/tools/ai/#your-own-actions) list itself. The chips only appear while the AI tool is switched on and a provider is set up.

## Time zones

<SettingsPath path="Advanced / Selection actions / Time zones" />

The zones the Zones action renders a selected time in, reorderable, with a delete handle each. Below the list, a field searches every zone the device knows by city and by offset; tap a result to add it. With nothing picked the list is UTC and the device's own zone, and deleting everything returns to that.

## Details

- **Search, Translate, QR, Grammar and AI follow their tools.** Each is hidden when its tool is switched off on the [Tools](/reference/settings/tools/) screen, which includes tools that [power saving](/typing/power-saving/) or the lock screen have already taken away.
- **The screens are reachable by link** at `wmkeyboard://settings/selection_macros`, `selection_macros/actions`, `selection_macros/ai` and `selection_macros/zones`. See [Deep links](/reference/deep-links/).
- **The list resets once on this version.** The list of actions and its order are stored with a version. A list saved by an older version reads as the shipped list, so everyone gets the new actions; the same happens to a backup restored from an older version. Every change you make after that is kept.
- **Nothing here is read before your first unlock**, beyond the actions that only touch the field you are typing in. See [Selection actions](/smart/selection-actions/#details-and-edge-cases).
